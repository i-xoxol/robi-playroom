# Security

Please report vulnerabilities privately through the repository's Security tab
if private reporting is enabled. Do not include API keys, family passwords,
children's speech, personal data or deployment databases in issues or pull
requests. If private reporting is unavailable, open an issue that asks for a
private contact channel without describing an exploitable vulnerability.

Keep paid endpoints behind authentication and HTTPS. Run your own deployment
with your own provider account and private configuration. Review current provider
requirements for applications used by children; the application cannot verify
account-level retention settings.
